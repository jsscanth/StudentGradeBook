# Student Grade Book 

A python-based command prompt application to help record student grade and show its average, letter grade, class average, and ranked grade. 

## Overview

This project is a student grade record book developed using python.

It allows user to write student name and their grades, get student average and letter grade, get class average through command line interface.

## Features

- Add student
- Add grades 
- Get student's average
- Get student's letter grade
- Get student highest grade
- Get student lowest grade
- Get class average
- Get ranking of grade
